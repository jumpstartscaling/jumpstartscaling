## 🎓 KNOWLEDGE TRANSFER

### Key Design Decisions

1. **Dual-Output Logging**: Terminal (Pino) + Database (work_log) for both real-time visibility and historical analysis

2. **Type-Safe Actions**: Astro 5 actions with Zod validation prevent runtime errors and provide IDE autocomplete

3. **Heartbeat Service**: Background monitoring prevents cold starts and enables auto-healing

4. **PostgreSQL Sentinel**: Database triggers notify Python workers instantly via pg_notify

5. **Web Speech API**: Native browser API for voice feedback (more compatible than react-use)

6. **Station Seeding**: New sites auto-provision with navigation, SEO rules, and templates

7. **Framer Motion**: Smooth animations make the UI feel premium and responsive

### Anti-Patterns Avoided

- ❌ Raw `process.env` (used Astro 5 env schema instead)
- ❌ Circular dependencies (used dynamic imports)
- ❌ Client-side secrets (marked server-only in env schema)
- ❌ Unvalidated inputs (Zod on all action inputs)
- ❌ Missing error handling (try/catch + ActionError everywhere)
- ❌ Hardcoded values (registry-based configuration)
